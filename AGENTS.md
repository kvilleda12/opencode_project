# Project constraints

- Continue Baseline, a basketball guide for new players and fans, in this class repository.
- Use original or invented public-facing content: a heading, introduction, and at least two meaningful content sections. Replace placeholders.
- Keep the site dependency-free using HTML, CSS, and JavaScript in `public/`; no build step is needed.
- Include working interactions, responsive layouts, readable text, visible keyboard focus, and keyboard-operable controls.
- Serve over localhost HTTP; document exact startup and shutdown commands.
- Work on a descriptive Git branch, commit with a descriptive message, and push that branch to this repository. Do not submit a PR to the shared class repository.
- Include README.md, AGENTS.md, REFLECTION.md, and genuine browser evidence with the localhost address bar visible.
- Exclude dependencies, generated build output, credentials, and unrelated files. Do not expose private browser content in screenshots.
- Document actual checks and limitations honestly. The student must review the site themselves and ensure the instructor has repository access.
- Keep this assignment as a local-server project; do not deploy it to a hosting service.
